Que souhaitez-vous faire de ce projet ?

Choisissez une option — vous pourrez la modifier tant que le projet n'est pas publié.

OPTION 1

Rester confidentiel

Vous gardez votre idée 100% privée. Téléchargez votre rapport complet (modèle, valeur, risques) pour votre usage personnel ou une levée de fonds externe.

OPTION 2

Proposer à la vente

Votre projet est listé dans la Vitrine. Les entreprises intéressées achètent un code d'accès par Mobile Money pour consulter le dossier complet.

OPTION 3

Chercher un partenariat

Vous ne vendez pas le projet — vous cherchez un partenaire ou investisseur. Accès à la proposition déverrouillé par code Mobile Money.

Votre rapport reste entièrement privé — rien n'est publié. Téléchargez-le en Excel ou PDF depuis l'onglet « Score & recommandations » (bouton d'export en bas des résultats).
